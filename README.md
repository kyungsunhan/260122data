# 서울 일 기온 비교 Streamlit 웹앱

이 프로젝트는 **서울(지점 108) 일별 기온 자료(1904–현재)**를 기반으로,

* 기본 기온 데이터를 탑재한 상태에서
* 동일 형식의 CSV 파일이 추가로 업로드되면 자동으로 병합하고
* 특정 날짜(기본값: 최신 날짜)가 **같은 월–일 기준 과거 기온 분포에 비해 얼마나 추웠거나 더웠는지**를
* **Plotly 기반 인터랙티브 그래프**로 시각화하는 Streamlit Cloud 웹앱입니다.

기후·환경 연구, 교육, 데이터 시각화 데모 용도로 바로 활용할 수 있도록 설계되었습니다.

---

## 1. 주요 기능

### 1) 기본 데이터 + 추가 업로드 자동 병합

* 기본 서울 일 기온 데이터(`base_seoul_temp.csv`)를 앱 시작 시 자동 로드
* 동일 형식의 CSV 파일을 하나 이상 업로드하면

  * 컬럼 자동 정규화
  * 날짜·지점 기준 중복 제거
  * 기존 데이터와 즉시 병합

### 2) 같은 날짜(월–일) 기준 기온 비교

선택한 날짜에 대해 다음 정보를 제공합니다.

* 해당 날짜의 실제 기온 값
* 같은 **월–일(MM-DD)** 에 해당하는 과거 모든 연도의 기온 분포
* 역사적 평균 대비 편차(℃)
* 백분위(percentile, 낮을수록 더 추운 쪽)
* 추운 순 / 더운 순 랭킹
* Z-score (가능한 경우)

※ 날짜를 지정하지 않으면 **데이터 내 최신 날짜**가 자동 선택됩니다.

### 3) Plotly 기반 인터랙티브 시각화

* 전체 기간 시계열(Line chart)
* 동일 월–일 기준 역사적 분포(Box plot + 점)
* 동일 월–일 연도별 비교(Bar chart)

모든 그래프는 확대, 툴팁, 범위 선택 등 인터랙션을 지원합니다.

### 4) 데이터 품질 확인

* 결측치 개수 요약
* 물리적으로 비현실적인 기온 범위(기본: -35℃ ~ 45℃) 자동 점검

---

## 2. 데이터 형식

모든 CSV 파일은 아래 **5개 컬럼을 동일한 순서**로 가져야 합니다.

| 컬럼명     | 설명                           |
| ------- | ---------------------------- |
| 날짜      | 관측일 (YYYYMMDD 또는 YYYY-MM-DD) |
| 지점      | 관측 지점 코드 (서울 = 108)          |
| 평균기온(℃) | 일 평균기온                       |
| 최저기온(℃) | 일 최저기온                       |
| 최고기온(℃) | 일 최고기온                       |

> 엑셀에서 병합 셀·제목 행이 포함된 경우라도, 실제 데이터가 5개 컬럼 순서를 유지하면 자동으로 보정됩니다.

## 3. 프로젝트 구조

```
.
├─ app.py                 # Streamlit 메인 앱
├─ requirements.txt       # Streamlit Cloud 의존성
└─ data/
   └─ base_seoul_temp.csv # 기본 탑재 서울 기온 데이터
```

---

## 4. 실행 방법

### 1) 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 자동으로 앱이 열립니다.

### 2) Streamlit Cloud 배포

1. 이 프로젝트를 GitHub 저장소로 업로드
2. Streamlit Cloud에서 새 앱 생성
3. `app.py` 선택
4. 자동 배포 완료

---

## 5. 사용 방법

1. 앱 실행 후 좌측 사이드바에서

   * 지점 코드 (기본: 108)
   * 비교 지표 (평균 / 최저 / 최고기온)
   * 기준 날짜 선택
2. 필요 시 동일 형식의 CSV 파일 추가 업로드
3. 메인 화면에서

   * 요약 문장(얼마나 추웠/더웠는지)
   * 시계열 및 분포 그래프 확인

## 6. 사용 기술 스택

* **Python 3.10+**
* **Streamlit** – 웹 UI 및 배포
* **pandas** – 데이터 정제 및 시계열 처리
* **Plotly** – 인터랙티브 시각화

---

## 7. 확장 아이디어 (향후 개선)

* 30년 기후평년(예: 1991–2020) 기준 비교 옵션
* ±7일 이동창(window) 기반 비교
* 이상기온 이벤트 자동 탐지
* 다른 지점(전국) 다중 선택 지원
* 월·계절 단위 통계 요약
